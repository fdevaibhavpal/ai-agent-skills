# Example: React performance

A real run of `cr-gaps` on 2026-10-17: audience intermediate React developers, publishing on YouTube, 90-day window, quick depth.

- [`report.md`](report.md): the finished report. Tables and bars were produced by `scripts/render.py`; the prose was written from `opportunities.json` and the evidence.
- [`opportunities.json`](opportunities.json): the scored output of `scripts/score.py`.
- [`topics.json`](topics.json): the topic vocabulary the run used.

The raw collected records are not kept in the repository. They are working data, and some of the text in them belongs to other people. To reproduce a run, follow [`../../actions/_pipeline.md`](../../actions/_pipeline.md); the numbers will differ because the sources change.

What this run could not see is listed in the report's Limits, and it is worth reading first.
